# WGS Figma Archive Workflow

`INBOX → AUDIT → SALVAGE → DEVELOP → SYSTEMISE → PUBLISH`

## Score each concept

Score 1–5 with one evidence note for idea, art direction, strategy, originality,
execution, implementation feasibility, and portfolio potential. Do not average
away a fatal weakness; name it.

## Outcomes

- **ARCHIVE** — preserve, no current development value.
- **SALVAGE** — retain a specific idea, asset, or interaction only.
- **DEVELOP** — a promising concept needs strategic or execution work.
- **PUBLISH** — complete, truthful, feasible, and portfolio-ready after QA.
- **REFERENCE ONLY** — useful learning, not WGS work to present.

## Audit record

Capture file/node link, owner, date, project context, score evidence, strongest
element, generic/AI-looking element, missing proof, technical risk, salvage plan,
and next decision. Do not modify original archive frames during audit.

## Publish gate

Apply `WGS-CASE-STUDY-STANDARD.md`. Do not publish weak work merely to increase
portfolio count.
