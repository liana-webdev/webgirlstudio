# WGS Creative Direction Bible

## Creative Philosophy

WGS joins beauty and usability through strategic creativity, emotional design,
and human craft. AI may accelerate exploration and production; it does not choose
what matters. Avoid AI sameness through specific content, coherent constraints,
deliberate editing, and accountable creative direction.

Experimentation must not create ambiguity. Use purpose before decoration and one
distinctive idea per section rather than stacking every technique together.

## Creative Process

Discovery → brief → three territories → moodboard → previs → styleframes →
prototype → motion → build → critique/dailies → finaling.

A moodboard records relationships and decisions, not only attractive images.
A prototype tests hierarchy, interaction, and feasibility. Styleframes must be
tested against real copy and responsive states.

## Art Direction Toolkit

Possible languages include typography-led systems, strict or broken grids,
editorial composition, photography, illustration, tactile texture, 3D, geometry,
brutalism, luxury, organic systems, cinematic design, futuristic systems, and
restrained minimalism. None is a mandatory WGS style. Select a language because
it expresses the brief and survives implementation.

For each chosen language define hierarchy, type roles, palette logic, image
treatment, spacing rhythm, material behaviour, motion grammar, responsive change,
and what not to do.

## Motion Direction

Motion should primarily orient, reveal, explain, respond, or create atmosphere.
Define trigger, duration/rhythm, continuity, interruption behaviour, reduced-
motion alternative, and performance budget before selecting a library.

## Interaction Library

Possible patterns: magnetic links, shared-element transitions, pinned
storytelling, horizontal galleries, cursor-responsive media, parallax,
typography animation, interactive 3D, progressive disclosure, and responsive
transformations. Use a pattern only when its interaction is discoverable and its
fallback preserves the task.

## Cinematic Thinking

Translate film language into web through establishing shots, framing, close-up,
point of view, pacing, sequencing, reveal, motif, rhythm, contrast, colour script,
and transitions. The visitor controls pace; cinematic direction must respect
scroll, input, loading, accessibility, and return visits.

## Reference Directory

Maintain references in `WGS-REFERENCE-LIBRARY.md` under websites, studios, films,
title sequences, fashion, photography, architecture, games, and editorial design.
Record the useful principle, not only a URL or image.

## Project Postmortems

Record what worked, failed, looked generic, felt AI-generated, was technically
expensive, and should become reusable. Use the project `POSTMORTEM.md` template.
