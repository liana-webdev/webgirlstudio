# WGS Cinematic Language

## Translation to web

| Film device | Web equivalent | Risk |
|---|---|---|
| Establishing shot | Opening state that establishes world and current action | atmosphere obscures the offer |
| Close-up | Focused interface/media detail | context disappears |
| Point of view | Content order shaped around a specific visitor intent | other journeys become invisible |
| Pacing | Section density, scroll length, transition rhythm | forced or slow navigation |
| Reveal | Progressive disclosure of context or proof | critical information hidden |
| Motif | Repeated visual/motion signal | ornamental repetition |
| Colour script | Planned emotional palette change across a journey | contrast/accessibility failure |
| Cut/transition | State or route transition | disorientation or latency |

## Rules

- Preserve user control; the site is not a non-interactive film.
- Let sequence strengthen meaning, not delay access.
- Use sound only with explicit control and a silent default.
- Provide a reduced-motion/static composition with equivalent information.
- Test returning-user speed as well as first-visit atmosphere.
