# WGS Figma Audit

Read the Source Manifest, Figma Archive Workflow, Case Study Standard, and
Creative Direction Bible. Use the relevant Figma read tool without modifying
original archive frames during audit.

1. Inventory file/node, owner, date, context, and source status.
2. Score idea, art direction, strategy, originality, execution, implementation
   feasibility, and portfolio potential from 1–5 with evidence.
3. Name strongest element, generic/AI-looking element, missing proof, and risk.
4. Route to ARCHIVE, SALVAGE, DEVELOP, PUBLISH, or REFERENCE ONLY.
5. Define the smallest next step and preserve provenance.

Produce a scored audit table. Pass the gate only when publish recommendations
meet the portfolio standard rather than project-count goals.
