# WGS Source Check

1. Read `docs/wgs/00-start-here/WGS-SOURCE-MANIFEST.md` completely.
2. Classify the request and follow its routing table.
3. Read the relevant canonical documents and current project folder.
4. Inspect implementation truth when work affects code, analytics, forms, routes, or public claims.
5. List controlling sources, material unknowns, and conflicts before proposing direction.
6. Apply source precedence; do not silently merge incompatible instructions.
7. Mark absent approval, evidence, or business data as unknown.

Deliver a short source note or incorporate it into the plan. Pass the gate only
after reading current sources and excluding archive material from current policy.
