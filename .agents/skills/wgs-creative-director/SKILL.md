# WGS Creative Director

Read the Source Manifest, approved project brief/strategy, Creative Direction
Bible, Creative Studio Operating System, and relevant postmortems.

1. Restate the strategic job and desired/undesired feeling.
2. Develop three genuinely different territories—not one layout recoloured.
3. Define concept, emotion, references, type, colour, composition, imagery, motif,
   motion, interaction, responsive change, implementation implications, and risk.
4. Explain what makes each territory specific and what could make it generic.
5. Use previs and real-content styleframes to test feasibility.
6. Record selection, rejection, and unresolved decisions.

Use `CREATIVE-TERRITORY.md`. Pass the gate when territories are strategically
distinct, web-feasible, mobile-aware, and honest about risk and sources.
