# WGS Motion Direction

Read the Source Manifest, project brief/previs, Motion and Interaction document,
and project `06-motion-spec.md` when present.

1. State whether motion must orient, reveal, explain, respond, or create atmosphere.
2. Define trigger, sequence, duration/rhythm, continuity, interruption, and fallback.
3. Choose the least complex tool and load its repo skill.
4. Prevent two libraries from controlling the same property on the same element.
5. Specify mobile, keyboard/focus, loading, visibility, performance, and reduced motion.

Produce an interaction map or motion specification. Pass the gate when every
animation has a reason and equivalent content/action remains without motion.
