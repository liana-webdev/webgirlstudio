# WGS Web Art Direction

Read the Source Manifest, project creative direction, Design Rules, Design System,
and Creative Direction Bible.

1. Define type roles, palette logic, spacing rhythm, grid, image treatment, motif,
   interface states, and one distinctive idea per section.
2. Apply the direction to real navigation, controls, forms, galleries, and content.
3. Design mobile transformations rather than scaled desktop frames.
4. Specify focus, contrast, affordance, loading, error, and reduced-motion states.
5. Identify production assets and implementation risks.

Produce a design specification or review tied to the approved territory. Pass the
gate when it is legible, web-native, responsive, buildable, and avoids fake UI.
